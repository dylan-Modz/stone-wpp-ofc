01 / Comece aqui

Instalação

Instale a Stone WPP em seu projeto Node.js usando o gerenciador de pacotes da sua preferência. O pacote oficial é @stone-wpp/ofc.

Terminal · npm
npm install @stone-wpp/ofc

Requisitos: Node.js 20 ou superior. O pacote utiliza ES Modules (ESM).

Nota: Stone WPP é uma biblioteca para desenvolvedores — não é um bot pronto para executar com npm start. Crie sua aplicação e importe os módulos necessários.
02 / Configure

Primeiros passos

Inicialize uma sessão e acompanhe os eventos de conexão. Este exemplo segue o padrão publicado no README oficial do projeto.

JavaScript · app.js
import createStone, { useMultiFileAuthState } from '@stone-wpp/ofc'

const { state, saveCreds } =
  await useMultiFileAuthState('./sessao')

const stone = createStone({ auth: state })

stone.ev.on('creds.update', saveCreds)

stone.ev.on('connection.update', ({ connection }) => {
  console.log('[ STONE ]', connection)
})
  1. Instale a biblioteca e configure seu projeto para utilizar módulos ES.
  2. Crie o estado de autenticação e inicialize o socket.
  3. Escute os eventos e persista as credenciais em local seguro.
03 / Segurança

Autenticação e sessões

O estado de autenticação mantém os dados necessários para a conexão. No exemplo de inicialização, useMultiFileAuthState fornece o estado e a função de persistência, e creds.update sinaliza mudanças nas credenciais.

Atenção: nunca publique pastas de sessão, credenciais ou tokens no GitHub. Use armazenamento protegido, com permissões de acesso adequadas.

Para conhecer outras opções e tipos exportados, consulte os módulos Utils, Socket e Types do repositório.

05 / Comunicação

Mensagens e eventos

O socket da Stone concentra recursos de comunicação. Os módulos exportados incluem Socket, WAM, WABinary e WAUSync, além dos tipos de apoio.

Ao implementar recursos de mensagens, confira os nomes dos métodos e os formatos dos argumentos diretamente na versão que você instalou, pois a biblioteca está em desenvolvimento.

Explorar o código da biblioteca ↗
06 / Interação

Botões e mensagens interativas

O projeto contempla estruturas de interação para mensagens. A compatibilidade e os tipos de interação variam conforme a implementação e a versão do WhatsApp.

Consulte o código-fonte e os tipos exportados antes de utilizar listas, botões ou outros formatos interativos. Não presuma suporte a um recurso apenas porque ele aparece como planejado.

07 / Organização

Grupos, comunidades e canais

A biblioteca tem módulos voltados a operações de grupos, comunidades e canais. Trabalhe com os métodos e eventos documentados pelo código da versão instalada, respeitando permissões de participantes e administradores.

Compatibilidade: alguns recursos podem depender de alterações no protocolo ou de permissões específicas da conta conectada.
08 / Arquitetura

Extensions e DataLayer

O pacote exporta módulos de Extensions e DataLayer, que ajudam a compor integrações e recursos de armazenamento na aplicação.

Para integrações avançadas, confira as interfaces e exports diretamente nas pastas oficiais do projeto.

09 / Ajuda

Perguntas frequentes

A Stone WPP é um bot completo?

Não. É uma biblioteca Node.js para que você desenvolva e mantenha seus próprios projetos.

Qual versão do Node.js é necessária?

O pacote informa suporte a Node.js 20 ou superior. Confira também os requisitos das dependências nativas no seu ambiente.

Funciona no Termux?

É possível tentar a instalação no Termux com Node.js LTS; alguns pacotes podem exigir compilação ou suporte nativo no Android.

Como comunicar um problema?

Abra uma issue no repositório do GitHub com os passos para reproduzir, a versão utilizada e os logs sem informações sensíveis.
